# Suryansh Kumar – Personal Portfolio Website

A responsive personal portfolio website built using **HTML, CSS, JavaScript, and React.js** to showcase my skills, projects, education, and contact information.

## Features
- Modern and responsive user interface
- About Me section
- Technical skills showcase
- Projects section with technology tags
- Contact form with email integration
- Dark and light theme toggle
- Smooth navigation between sections
- Mobile-friendly design

## Technologies Used
- **HTML5** – Website structure
- **CSS3** – Styling, layouts, animations, and responsive design
- **JavaScript** – Interactive functionality
- **React.js** – Component-based user interface

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser to run the HTML/CSS/JavaScript version.
4. For the React version, create a React project using Vite, place `App.jsx` and `style.css` inside `src`, and run `npm run dev`.

## Purpose
This project helps me practice frontend development and create an online portfolio to showcase my technical skills and projects to recruiters.
